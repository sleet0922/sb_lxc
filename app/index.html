Complex Demo Container

由 sb_lxc build 从 Incusfile 一键构建

服务列表

🌐 Nginx - Web 服务 (端口 80/tcp)
🐍 Python App - 自定义应用 (端口 8080)
🔧 DNSmasq - DNS 服务 (端口 5353/udp)
🔐 SSH - 远程登录 (端口 22/tcp, root/toor)

构建特性

  • RUN/COPY/ENV 按顺序执行
  • ENV 变量跨指令引用
  • COPY 依赖前置 RUN 创建目录
  • 多端口 TCP + UDP 映射
  • DOMAIN 域名映射
  • AUTOSTART 开机自启
